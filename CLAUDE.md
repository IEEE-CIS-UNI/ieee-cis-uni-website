# Memoria del proyecto

`MEMORIA.md` guarda las decisiones, avisos, pendientes y el historial de sesiones.
Al terminar cada conversación con cambios, actualízala:

- Agrega una entrada en "Historial de sesiones" (fecha, qué se hizo, decisiones).
- Actualiza "Decisiones tomadas", "Cosas a tener en cuenta" y "Pendientes" si cambiaron.
- Nada privado: el archivo está en GitHub.
